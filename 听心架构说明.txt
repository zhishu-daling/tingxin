一、概述
═══════════════════════════════════════════════════════════════

听心是一个端到端的 AI 语音情感分析系统。
输入：音频文件（MP3/WAV等）
输出：逐句转录 + 声学分析 + 情绪标签 + 防御机制识别 + 伪装检测 + 白话总结

核心特点：
  1. 白盒架构 — 每一层分析都可追溯、可解释
  2. MEITR 五维框架 — 唤醒度(A)/效价(V)/控制度(D) 三维情绪建模
  3. 双人交互分析 — 能量耦合度、音高追随度、关系模式判定
  4. 压力预测 — 基于 P_suppress 的情绪爆发预测
  5. 伪装检测 — 声文矛盾 + 过度控制检测

四、各模块详细说明
═══════════════════════════════════════════════════════════════

4.1 preprocess.py — 音频预处理
──────────────────────────────
  load_audio(path, sr=16000)    → 加载并重采样
  split_audio(audio, sr, ms)    → 按毫秒切割音频块
  get_duration(path)            → 获取音频时长
  
  依赖：librosa / soundfile / numpy


4.2 asr.py — 语音识别
──────────────────────────────
  transcribe(audio, sr)         → 返回 [{start, end, text, probability}]
  
  使用：Whisper 模型（GPU加速）
  特性：子进程持久化运行，避免每次加载模型


4.3 diarize.py — 说话人分离
──────────────────────────────
  diarize(segments, audio_path) → 对片段聚类标注说话人
  
  方法：MFCC 特征提取 → 互相关对齐 → K-Means 聚类
  IncrementalDiarizer: 增量式聚类，支持流式处理
  batch_refine(): 最终精校


4.4 acoustic_features.py — 声学基元提取
────────────────────────────────────────
  extract_segment_features(audio, sr) → dict 包含：
  
  - energy_mean / energy_std       # 能量均值/标准差
  - pitch_mean / pitch_std         # 基频均值/标准差（Hz）
  - zcr_mean                       # 过零率
  - spectral_centroid_mean         # 频谱质心
  - mfcc_mean / mfcc_std           # MFCC 特征（13维）
  - decay_time_s                   # 衰减时间
  - has_micro_pause                # 微停顿检测
  - formant_freqs                  # 共振峰频率（F1/F2/F3）


4.5 analysis.py — ★ 核心分析引擎
───────────────────────────────────
  
  【A. 情绪三维向量 A/V/D】
  唤醒度 Arousal:   高=激动/紧张，低=平静/疲惫
                    公式: tanh(0.4*能量 + 0.35*音高 + 0.25*节奏 - 0.1)
                    范围: [-1, 1]
  
  效价 Valence:     正=积极/开心，负=消极/低落
                    公式: tanh(0.4*反平坦度 + 0.35*反质心 + 0.25*HNR)
                    范围: [-1, 1]
  
  控制度 Dominance: 高=自信/强势，低=顺从/无力
                    公式: tanh(0.45*反音高方差 + 0.35*反能量加速度 + 0.2*稳定性)
                    范围: [-1, 1]
  
  【B. 情绪标签映射（7类）】
  (A>0.3, V>0.3)       → 兴奋
  (A>0.3, V<-0.3, D<-0.3) → 愤怒
  (A>0.3, V<-0.3, D>0.3) → 冷蔑视
  (A<-0.3, V<-0.3)     → 低落
  (A<-0.3, V>0.3)     → 平静
  (A>0.3, |V|<0.2, D<-0.3) → 焦虑
  (V<-0.3, |D|<0.3)   → 压抑
  (A>0.5)             → 激动
  其余 → 中性

  【C. 防御机制识别（10种）】
  压抑     — 努力控制情绪，不让真实感受流露
  否认     — 嘴上说没事但声音暴露焦虑
  投射     — 把自己的问题说成对方的
  合理化   — 用逻辑解释掩盖真实感受
  理智化   — 用分析/理论回避情感
  幽默化   — 用开玩笑缓解紧张
  回避     — 不想继续话题
  攻击转向 — 把情绪转嫁他人
  顺从     — 被迫接受但内心不认同
  反向形成 — 用相反情绪掩盖真实感受

  判断依据: A/V/D匹配程度 + 关键词命中 + 冲突分数

  【D. 声文矛盾检测】
  conflict_score = |文本情感 - 声学效价| × (1-|控制度|) × |唤醒度|
  分数 > 0.3: 明显不一致
  分数 > 0.4: 显著矛盾

  【E. 状态预测（爆发检测）】
  P_suppress = |A| × conflict × (1 + cum_strain)
  cum_strain = 0.95 × 上一轮累积 + |效价变化| × (1 - |D|)
  阈值 > 0.6: 爆发风险高 / 冷暴力风险

  【F. 伪装检测】
  fabrication = context_contradiction × overcontrol
  overcontrol = 音高过度稳定(0.4) + 衰减异常(0.35) + 微停顿缺失(0.25)
  基线对比: 跟TA自己比，不是跟全人类比

  【G. 双人交互分析】
  能量耦合度: Pearson相关系数(SPK1能量, SPK2能量)
  关系标签: >0.5=高同步 / >0.2=弱同步 / >-0.2=无关 / >-0.5=弱对抗 / 其他=强对抗


4.6 call_analysis.py — 电话客服分析
──────────────────────────────────────
  专门分析客服通话场景，额外功能：
  - 客户拒绝检测（30+关键词）
  - 投诉倾向检测
  - 客户情绪轨迹追踪
  - 问题电话自动标红
  - 批量通话统计（情绪分布/高频词/拒绝词聚类）


4.7 stream_pipeline.py — 流式管线
─────────────────────────────────────
  管线编排层，按顺序调用所有模块：
  
  1. VAD能量检测切句子（30ms帧/400ms静音阈值）
  2. 60秒块→Whisper批量ASR
  3. 增量说话人分离 + 最终精校
  4. 多线程并行声学特征提取（4线程）
  5. SpeakerBaseline 建立
  6. 逐段 MEITR 分析
  7. 组装结果 → 写JSON文件
  8. 返回 result dict


4.8 plain_report.py — 白话总结生成
─────────────────────────────────────
  读取 JSON，将技术指标翻译为自然语言：
  
  技术指标 → 白话映射表：
  唤醒>0.5     → "情绪投入度高" / "声音明显激动/紧张"
  效价<-0.3    → "情绪偏负面" / "听起来低落"
  冲突>0.4     → "嘴上说的和真实情绪明显不一致"
  防御=压抑    → "在努力控制情绪，不让真实感受流露"
  爆发风险     → "情绪压力积累快到达阈值"
  伪装>0.3     → "说话修饰痕迹重，可能在刻意表现"
