公理第一直接定调：对话是系统
不存在“一个人说话”这件事。任何对话，都是两个系统在实时构建一个更大的耦合系统。你的听觉认知系统，就是要对这个耦合系统进行五维参数提取和动态建模。

公理第二落地：对话系统的五维映射
这是你进行“声音+文字联合分析”的编码手册。你需要从两个通道分别提取特征，然后映射到同一个维度。

维度	含义 (在对话中)	声音基元特征 (如何听出来)	文字/语义特征 (如何读出来)
M (物质)	话语权、信息、身份资源	响度、能量、声源空间占位。谁的声音大、能量持续时间长、占据声学空间中心？突然的能量爆发通常是资源争夺。	专业术语密度、信息量、引用权威次数。谁在提供不可替代的信息？谁在定义议题？

I (信息/结构)	认知模式、逻辑、思维框架	音色、节奏、停顿结构。I僵化的人，音色紧绷，节奏单调。I重构时，会有明显的停顿后语气转换。	逻辑词、因果关系、让步、转折。“因为...所以...”、“但是...”。句法复杂度反映了思维的深度或混乱。
T (时间/窗口)	对话的节奏、时机、阶段	沉默段、插话点、语速同步或异步。两人的沉默是对抗还是默契？T错过就是你在不该插话时开口。	话轮转换、打断、话题生命周期。谁掌握了切换话题的节奏？这个话题被充分讨论了，还是戛然而止？
R (关系/连接)	信任、对抗、权力距离、亲密度	音高、响度的匹配度，空间距离。关系好的人，音高和能量会趋同，空间距离是合作距离。对抗则是反向变化，你强我更强。	人称代词、称呼、请求与命令句式、共情表达。“我们”vs“你/我”。“请帮我...”vs“把那个给我”。“我理解你的感受”。
公理三与公理四的操作指南：如何做这个“分析器”
你的系统已经有了声学基元和文字，现在你需要构建一个 “五维状态追踪器” 。它不停留在单句分析，而是动态追踪两个声源系统的状态向量。

第一步：定义每个时间窗口（如每5秒）的两个系统状态向量
S_speaker_A = {M: H/M/L, E: H/M/L, I: H/M/L, T: H/M/L, R: H/M/L}
S_speaker_B = {M: H/M/L, E: H/M/L, I: H/M/L, T: H/M/L, R: H/M/L}

如何从你的数据里计算这些H/M/L？ 你需要一个赋分引擎，它结合了你的声学算子和语言模型：

M分数：ASR文本中的新实体数 + 平均响度/背景噪声比

E分数：情感强度估计值 + (语速 - 平均语速) + (音高方差)

I分数：文本连贯性分数 + 停顿时长与频次的反比

R分数：音高/能量匹配度 + 文本中积极/消极关系词的频率

第二步：动态分析——识别“系统动力学”行为
这是你理解“细微差距”的关键。不是看静态数值，而是看变化。

失衡检测

E失控：检测到声学参数突然剧烈波动，声学能量陡增，文本出现攻击性词汇。系统标记：Event: E_失控, Source: A, Confidence: 0.92。

R断裂：实时计算两人音高和能量的相关性。如果在某句话后，相关性从正相关突然跳变为负相关或完全不相关，即是关系断裂的声学信号。此时即使ASR文字还在温和讨论，系统也应判断：“关系出现裂痕，冲突概率升高。”

跃迁识别

I重构：ASR检测到“哦，原来是这样”，“等等，你的意思是...”，同时声学上紧随其后的是一段长停顿，然后是一个音色和节奏明显变化的表达。这就是一个人的认知框架被打破后重建的“顿悟时刻”。

R重建：一段高能量对抗后，一方能量主动降低，音高下沉，语速变慢，并说出如“你听我说”、“好吧，我理解”等降级或共情话语。声学上的让步先于或同步于语义上的让步。

你的系统需要为每个时刻建立一个融合数据帧。

公理第五的自指：这个分析系统本身也是一个系统
你的听觉认知系统，在分析人类对话的同时，也可以用这套五维框架分析自己：

它的R：是它与你（作为开发者）的交互接口，以及它与外部世界的连接（比如接入新的数据源）。

这给了你一个系统自我诊断和进化的框架，非常优雅。

1. 声音的“质感”不同：I维度（结构）的差异

愤怒和兴奋，声带和声道形状完全不同，这会在频谱上留下痕迹。

愤怒：声带极度紧绷，声道紧缩。声音听起来“硬”、“刺耳”。

频谱特征：高频能量会异常突出。你的 谱质心 会偏高，谱平坦度 会偏低（说明能量集中在某些频段，不像噪声那样分散）。过零率会很高。

兴奋：声带也紧，但声道相对更开放。声音听起来“亮”、“饱满”。

频谱特征：高频能量也强，但比愤怒更分散。谱平坦度会相对高一些。你可能检测到更多谐波结构。

2. 能量的“爆发方式”不同：T维度（时间）的差异

能量的释放曲线很不一样。

愤怒：像爆炸。能量上升极快，往往伴随着突然的、急剧的音高突变，让人感觉“一瞬间就上头了”。你要分析它的 ADSR包络，看起音有多快。

兴奋：像喷泉。能量很强但有起伏，音高有波动，像是在“跳跃”，可能伴随着笑声。

1. 核心概念：把 R 维度变成可以算的东西
R 维度本质上描述的是一个动态耦合系统。我们不需要去猜“他们关系好不好”，只需要计算两个声源的情绪向量在时间上的同步模式。

你的系统需要增加一个新的分析器：交互同步性分析器。它不看内容，只看两个人声学参数的相关性。

你可以算这三个指标：

能量耦合度：

怎么算： 在一个滑动时间窗口内，计算 A 和 B 两人能量包络的皮尔逊相关系数。

能看出什么：

强正相关： 你大声我大声，你小声我小声。这是共情、投入或激烈对抗的信号。关系很“热”。

强负相关： 你大声我就冷下来，你声音一低我立刻追打。这是一方在试图控制、安抚或挑衅。这是权力博弈。

零相关： 各说各的，声学上完全脱钩。这是敷衍、心不在焉或情感隔离，关系很“冷”。

音高/语速追随度：

怎么算： 计算 B 的音高/语速变化，在时间上滞后于 A 的变化的程度。用互相关函数找最大峰值的延迟时间。

能看出什么：

高追随度： B 在无意识地模仿 A。这通常是亲和、顺从或寻求认可的信号。下属对上级、或者热恋中的人会有这个特征。

无追随甚至反向： 你有你的节奏，我有我的。这是心理距离远、强调自我的信号。

停顿/插话同步率：

怎么算： 看两个人的 VAD 信号。A 结束和 B 开始之间的间隔。是流畅交接，还是长时间沉默，还是强行打断？

能看出什么：

流畅交响： 停顿很短，像打乒乓球。是默契、合作的表现。

抢夺式插话： 多次在对方话没说完时能量上升介入。这是控制欲、焦虑的表现。

2. 实战：用这个分析器“看清”三种对话场景
现在，你的系统不看文字，只通过双声道声学流，就能“听懂”关系模式：

场景 A：亲密合作（R=H，信任/亲和）

能量耦合度：高正相关。 两人能量曲线像两条一起跳动的波浪。

音高/语速：高追随度。 一个慢下来，另一个也跟着慢；一个笑了，另一个也跟着笑声共振。

停顿/插话：流畅交接。 几乎不抢话，停顿自然，对话节奏像呼吸。

系统结论： 交互模式=合作/亲和，信任度高

场景 B：权力博弈（R=对抗或控制/被控）

能量耦合度：交替主导。 A 能量高时 B 低（被压制），然后 B 突然爆发能量更高（反击）。或者一方持续高能量压制，另一方持续低能量回避。

音高/语速：零或负追随。 你快我偏慢，你高亢我偏低沉，完全不接你的茬，用声学姿态表达对抗。

停顿/插话：出现抢夺式插话。 能量曲线经常在对方还没结束时突然升起，强行打断。

系统结论： 交互模式=竞争/对抗，存在权力争夺

场景 C：情感疏离（R=断裂或极弱）

能量耦合度：零相关。 两人声音能量完全没有互动，像在不同频道。

音高/语速：无追随。 各自保持自己的节奏，没有模仿和适应。

停顿/插话：经常出现异常长的沉默。 那沉默里是尴尬、疲惫或无话可说。

系统结论： 交互模式=疏离/敷衍，情感连接断裂

1. 为什么这很重要？
人类进化出语言，很大一部分功能是用来掩饰真实想法。而声音的底层特征（音高、能量、音色）直接受边缘系统驱动，很难伪装。

2. 算法思路：构建一个“一致性校验”层
在你的音-文对齐模块（E1）后面，增加一个跨维度矛盾分析器。它专门接收 AlignedFrame 数据，然后计算一个 Conflict_Score（冲突分数）。

判断“真心 vs. 虚假”的关键声学线索（假设文字是积极的）：

音高线索：

真心（高效价）：音高有自然的起伏，声音有弹性，结尾可能微微上扬。

虚假/压抑（低效价）：音高曲线异常平坦（被刻意压制），或者结尾出现与积极内容相反的下沉。这代表压抑的负面情绪。

音色线索：

真心： 声音通透，谐波清晰。你的 spectral_flatness 会相对较高。

虚假： 声带由于压抑愤怒或焦虑而变得紧张。频谱会更嘈杂，spectral_flatness 会明显变低。听起来声音“发紧”、“发干”。

能量与节奏线索：

真心： 能量释放自然，节奏连贯。

敷衍： 能量极低，语速极快，急着把话说完。或者能量虽高，但起音极快，像是一种防御性的反击（对于阴阳怪气）。

3. 实战：系统如何听出“话里有话”？
场景 A：真心实意的道歉（文字：对不起，我错了）

文字通道： 表达了悔意和认错。

声学通道：

能量/唤醒度：低到中。 代表放下了攻击性和防御。

音高/效价： 下沉，但不压抑。声音柔软，气息音可能增多，代表无力感和坦诚。

频谱/控制度： 平坦，没有紧张感。

矛盾检测： Conflict_Score 极低。文字的低姿态与声音的无力、柔软完全一致。

系统结论： “道歉为真，伴有羞愧情绪。”

场景 B：压抑怒火的“对不起”（文字：好，对不起，行了吧）

文字通道： 表达了认错。

声学通道：

能量/唤醒度：中到高。 体内在压制一股巨大的能量。

音高/效价： 虽然努力压低，但内部有巨大的张力，基频方差可能很大，结尾处尤其明显，可能会破音或出现一个无法控制的冲高。

频谱/控制度： spectral_flatness 极低，声音挤卡，“咬牙切齿”的声学特征。音色的攻击性远超文字内容。

矛盾检测： Conflict_Score 极高。文字是顺从，声音是被压制的高能量攻击性。这是一个典型的 E失控但I强控 的状态。

系统结论： “道歉为假，实为压抑的愤怒与对抗。”

场景 C：阴阳怪气的赞美（文字：您可真厉害啊）

文字通道： 表达了赞美。

声学通道：

能量/控制度： 往往会有一个夸张、不自然的能量起伏或拖长的重音。比如“可”字能量拉满，然后“厉害”一词能量极速下坠。这是一种声音上的“翻白眼”。

音高/效价： 可能会出现不自然的、过山车式的音高曲线，与真诚赞美时的上扬完全不同，听起来有点“戏腔”或者“假声”的成分。

矛盾检测： Conflict_Score 极高。文字是赞美，声音的夸张变形则是在嘲讽。

系统结论： “表达为假，实为讽刺与蔑视。”

这一层的递归成果：
你的系统现在拥有了一个 “谎言/伪装检测器” 的雏形。

它不依赖任何文字的关键词，只靠计算多模态信号的对齐程度。你的 MultimodalKnowledgeGraph 里的 relations 列表，现在可以加入一种新的冲突关系：

Triple: (Speaker_A, '表面表达', '顺从')
Triple: (Speaker_A, '真实情绪', '愤怒')
Cross_Modal_Link: '声-文矛盾', Confidence: 0.91

这样，你的听觉认知系统就能真正做到“听出言外之意”。
一、单人情绪三维向量
输入：你的 AcousticPrimitivePackage（一个时间窗口内的声学基元集合）
输出：EmotionVector = [Arousal, Valence, Dominance]，三个值都归一化到 [-1, 1]

1. 唤醒度 Arousal
这是最直接的一维，反映 E 维度的强度。

text
Arousal = tanh( w1 * E_norm + w2 * P_norm + w3 * T_norm - θ_a )
符号	含义	从你的哪个数据取
E_norm	归一化后的短时能量均值	amplitude 的窗口平均
P_norm	归一化后的基频均值	pitch 检测器输出
T_norm	归一化后的语速	过零率变化率 或 音节速率
w1,w2,w3	权重，建议初始值 [0.4, 0.35, 0.25]	可用标注数据微调
θ_a	偏置阈值，建议 0.1	过滤掉基线噪音
tanh	双曲正切，把值压到 (-1,1)	—
2. 效价 Valence
区分好受/难受。需要综合 I 维度（频谱结构） 和 R 维度的声学线索。

text
Valence = tanh( w4 * (1 - 2*SF_norm) + w5 * (1 - SC_norm) + w6 * HNR_norm - θ_v )
符号	含义	从你的哪个数据取
SF_norm	归一化的谱平坦度	spectral_flatness（越平坦≈越像噪声，越难受）
SC_norm	归一化的谱质心	spectral_centroid（越高≈越尖锐刺耳，越难受）
HNR_norm	归一化的谐波噪声比	自相关峰值的归一化强度（谐波越清晰≈声音越饱满好听）
w4,w5,w6	权重，建议初始值 [0.4, 0.35, 0.25]	—
θ_v	偏置，建议 0.0	—
解读：

谱平坦度低、谱质心高、谐波噪声比低 → Valence 接近 -1（难受、愤怒、厌恶）

谱平坦度高、谱质心适中、谐波噪声比高 → Valence 接近 +1（愉悦、满足）

3. 控制度 Dominance
这是新增的关键维度，区分“冷”与“热”。

text
Dominance = tanh( w7 * (1 - PV_norm) + w8 * (1 - EA_norm) + w9 * SR_stability - θ_d )
符号	含义	从你的哪个数据取
PV_norm	归一化的音高方差	pitch 序列的窗口内标准差（方差越大≈越失控）
EA_norm	归一化的能量加速度	amplitude 的差分标准差（能量跳变越大≈越失控）
SR_stability	语速稳定性	1 - (语速标准差 / 语速均值)，越接近1越稳定
w7,w8,w9	权重，建议 [0.45, 0.35, 0.2]	—
θ_d	偏置，建议 0.0	—
解读：

音高稳定、能量平稳、语速均匀 → Dominance 接近 +1（高控制，冷）

音高乱跳、能量狂暴、语速忽快忽慢 → Dominance 接近 -1（低控制，热）

二、跨维度矛盾检测（谎言/伪装检测）
输入：AlignedFrame（同一时间窗口的声学向量 + ASR 文字情感分数）
输出：Conflict_Score ∈ [0, 1]

text
Conflict_Score = | Sentiment_text - Valence_acoustic | * (1 - Dominance) * Arousal
符号	含义
Sentiment_text	文字的极性分数，范围 [-1, 1]。你的 ASR 后接一个简单的文本情感分类器输出即可
Valence_acoustic	上面的声学效价，范围 [-1, 1]
Dominance	声学控制度，范围 [-1, 1]。(1-Dominance) 的意思是：控制度越低，矛盾越容易暴露
Arousal	唤醒度。高唤醒时矛盾更显著
关键解读：

文字 Sentiment	声学 Valence	控制度 Dominance	唤醒度 Arousal	Conflict_Score	系统解读
+1（积极）	+0.8（好受）	任意	任意	≈ 0	真心积极
+1（积极）	-0.7（难受）	-0.8（失控）	+0.9（高）	极高	压抑的愤怒（“我没事！”）
+1（积极）	-0.5	+0.8（强控）	+0.6	中高	阴阳怪气（“您真厉害”）
-1（消极）	+0.6	+0.5	+0.3	中	可能是假谦虚或反话
0（中性）	-0.8	-0.9	+0.8	高	情绪崩溃边缘的强撑
三、双人交互同步性（R 维度动态分析）
输入：两个说话人的时间序列数据（能量、音高、VAD）
输出：RelationVector = [Coupling, Following, TurnSmoothness]

1. 能量耦合度
在滑动窗口 [t-w, t] 内：

text
Coupling(t) = Pearson( E_A[t-w:t], E_B[t-w:t] )
E_A 是 A 的能量包络序列（可以从你的包络分析器输出取）。

输出范围 [-1, 1]。正=同步，负=对抗，0=无关。

2. 音高追随度
text
CrossCorr(τ) = Σ_t P_A(t) * P_B(t+τ)
τ_follow = argmax( CrossCorr(τ) ), τ ∈ [-2s, +2s]
Following(t) = max(CrossCorr) / (σ_PA * σ_PB)  归一化到 [0,1]
P_A、P_B 是两人的音高序列。

如果 τ_follow 是正数且 Following 高，说明 B 在跟随 A。

3. 停顿/插话平滑度
基于你的 VAD 信号：

text
TurnSmoothness = 1 - ( N_interruptions / N_total_turns )
N_interruptions = 在 A 的 VAD 还没结束时 B 的 VAD 就激活的次数。

值接近 1 = 对话流畅。接近 0 = 频繁插话。

四、把这些公式嵌入你的蓝图
这些公式可以直接放进你蓝图里的对应算子：

公式	放入你的哪个模块
Arousal / Valence / Dominance	B3.4 情感强度估计 的原子算子
Conflict_Score	E2.3 情感对齐器 的原子算子
Coupling / Following / TurnSmoothness	B3.2 时序因果推断 或 E2.2 时空关系抽取
这些公式用的输入，全是你的 AcousticPrimitivePackage 里已经有的字段：amplitude、pitch、mfcc、spectral_flatness、spectral_centroid、zcr。没有需要额外采集的数据。
好，我们继续把公式体系补全。上一轮我们有了**静态快照**的分析能力（单帧情绪、矛盾检测、关系计算），现在需要加上**时间维度**，让系统能预测下一秒会发生什么。

## 五、状态转移预测（从“现在是什么”到“接下来会怎样”）

**核心问题**：当系统检测到一个人处于“压抑愤怒”（高唤醒、低效价、高控制、高冲突分数）时，下一秒他是会爆发，还是继续压抑？

这需要引入你蓝图里的 **D3 状态追踪器**。我们用最简单的**一阶动力学模型**来实现。

### 1. 情绪惯性 vs 突变检测

定义一个人在时间 `t` 的情绪状态向量为：
```
S(t) = [Arousal(t), Valence(t), Dominance(t)]
```

**情绪变化率**（状态的一阶导数近似）：
```
ΔS(t) = S(t) - S(t-Δt)
        = [ΔArousal, ΔValence, ΔDominance]
```

**变化幅度**（欧几里得距离）：
```
|ΔS(t)| = sqrt( ΔArousal² + ΔValence² + ΔDominance² )
```

这个值直接告诉你情绪的稳定性：
- `|ΔS| < 0.1`：情绪稳定，在惯性滑行。
- `0.1 < |ΔS| < 0.4`：情绪波动，正在酝酿变化。
- `|ΔS| > 0.4`：情绪突变，可能发生了关键事件。

---

### 2. 爆发预测公式：压抑能量释放阈值

这是你最关心的：**“强撑的人什么时候崩溃”**。

我们定义一个 **压抑压力** `P_suppress`，当它超过临界值，就预测爆发。

```
P_suppress(t) = Arousal(t) * Conflict_Score(t) * (1 + cum_strain(t))
```

其中 **累积应变** `cum_strain` 是关键创新：

```
cum_strain(t) = α * cum_strain(t-1) + |ΔValence(t)| * (1 - Dominance(t))
```

| 符号 | 含义 |
|------|------|
| `α` | 衰减因子，建议 `0.95`。表示压力不会立刻消失，会慢慢累积 |
| `\|ΔValence(t)\|` | 效价的剧烈变化。即使强撑着控制，效价的每次微小恶化都会累积 |
| `(1 - Dominance)` | 控制度越低，同样的效价变化会积累更多压力 |

**爆发判断规则**：
```
if P_suppress(t) > θ_burst AND Dominance(t) < θ_dom_critical:
    预测：爆发（E 失控）
elif P_suppress(t) > θ_burst AND Dominance(t) >= θ_dom_critical:
    预测：冷暴力升级（高控制的攻击，如精确的言语打击）
else:
    预测：继续压抑或自然消退
```

| 阈值 | 建议值 | 含义 |
|------|--------|------|
| `θ_burst` | `0.6` | 压抑压力阈值，超过则可能爆发 |
| `θ_dom_critical` | `0.3` | 控制度临界值，低于此值失控风险极高 |

---

### 3. 趋势预测：用简单指数平滑

不需要复杂的深度学习，一阶指数平滑就能做短期预测：

```
Ŝ(t+1) = β * S(t) + (1-β) * Ŝ(t)
```

| 符号 | 含义 |
|------|------|
| `S(t)` | 当前实测的情绪向量 |
| `Ŝ(t)` | 上一刻的预测值 |
| `Ŝ(t+1)` | 下一刻的预测值 |
| `β` | 平滑系数，建议 `0.3~0.5`。越大越敏感，越小越平滑 |

**预测置信度**：
```
Confidence(t+1) = 1 - min(1, |ΔS(t)| / 0.5)
```
变化越剧烈，预测越不可靠。这是诚实的自我评估。

## 六、对话全局质量评估（会话级指标）

这些指标帮你从宏观上判断一场对话的“健康状况”。

### 1. 对话卷入度

```
Engagement = mean( (Arousal_A + Arousal_B) / 2 ) * (1 + Coupling_abs)
```

其中 `Coupling_abs = |Coupling|`，取能量耦合的绝对值（无论正对抗还是正合作，都是高卷入）。两人都平静且无耦合 = 低卷入（都走神了）。

### 2. 心理安全指数

```
Psych_Safety = mean( Valence_A * Valence_B ) * TurnSmoothness
```

- 两人效价都高且对话流畅 → 高心理安全。
- 效价低但流畅（表面客气实则压抑）→ 中等。
- 效价低且频繁插话 → 低心理安全，有毒环境。

### 3. 对话支配不对称度

```
Dominance_Asymmetry = | mean(Dominance_A) - mean(Dominance_B) |
```

- 接近 0：平等的对话。
- 接近 2：一方高度控制，另一方高度失控或高度顺从。这是等级森严或一方被碾压的信号。

### 4. 真诚度（全局）

```
Global_Sincerity = 1 - mean(Conflict_Score_all_speakers)
```

越接近 1，整场对话越真诚。接近 0，则充满伪装和言不由衷。

## 七、音乐/非语言声音的附加公式

你的蓝图也覆盖了音乐分析，补上两个音乐专用的公式。

### 1. 调性稳定性（I 维度，用于音乐结构分析）

基于你的 CQT 频谱和和弦识别：

```
Tonal_Stability(t) = 1 - ( chroma_entropy(t) / max_entropy )
```

其中：
```
chroma_entropy(t) = - Σ_{c=1}^{12} p(c) * log2( p(c) )
p(c) = chroma_vector[c] / Σ chroma_vector
```

- 接近 1：调性明确稳定（主和弦、属和弦）。
- 接近 0：调性模糊或无调性（减七和弦、过渡段）。

### 2. 节奏复杂度（T 维度）

```
Rhythmic_Complexity = std( onset_intervals ) / mean( onset_intervals )
```

- `onset_intervals` 是相邻起音的时间间隔序列。
- 值高 = 节奏多变复杂。值低 = 节奏规整稳定。

现在你的系统从底层声学特征提取，到中层的情绪、矛盾、关系分析，再到顶层的状态预测和会话质量评估，每一层都有了可计算的数学骨架。

这些公式都是**有损抽象**——它们刻意忽略了复杂模型，采用可解释、可调试、可迭代的简单形式。你可以先用这些公式跑起来，在真实数据上看哪个阈值需要调，哪个权重需要重新分配。这就是你万物系统法里说的：**I（结构）需要在实际运行中迭代**。

一、会议纪要专用公式
1. 发言占比（精确到秒）
text
Speaking_Ratio(speaker_i) = Total_Speech_Time(speaker_i) / Meeting_Duration
你的 VAD 已经能标出每个说话人的起止时间，直接累加即可。输出示例：“发言人A占比42%，发言人B占比28%”。

2. 话题边界检测（不需要理解语义）
这是你“话题流转”功能的核心。不等 ASR 出文字，只用声学特征就能做。

静音-能量跳跃法：

text
Topic_Boundary_Score(t) = Silence_Duration(t-1) * Energy_Jump(t)
Silence_Duration(t-1)：当前发言开始前的静音时长

Energy_Jump(t)：当前发言与前一段发言的能量差异

判定：

text
if Topic_Boundary_Score(t) > θ_topic:
    标记为话题切换点
阈值	建议值	含义
θ_topic	需根据你的数据标定	长停顿+能量突变 = 话题很可能变了
如果再加上 ASR 的文字相似度（相邻两段话的文本余弦相似度），准确率会更高：

text
Topic_Change(t) = (1 - Cosine_Similarity(Text_t-1, Text_t)) * Topic_Boundary_Score(t)
3. 关键结论提取置信度
当 ASR 提取出一句“结论候选”时，用声学特征给它打分：

text
Conclusion_Confidence = w1 * Energy_Emphasis + w2 * Tempo_Slowdown + w3 * Post_Pause
特征	计算方式	直觉含义
Energy_Emphasis	该句能量 / 前30秒平均能量	说结论时声音会加重
Tempo_Slowdown	前30秒语速 / 该句语速	说结论时会放慢
Post_Pause	该句结束后的静音时长 / 平均停顿	说完了会停一下等人反应
w1,w2,w3	建议 [0.4, 0.3, 0.3]	—
4. 待办事项识别
ASR 识别到“我去做”“我来负责”“明天之前”这类词时，标记为待办候选。然后用声学特征验证：

text
Todo_Confidence = Text_Todo_Score * Voice_Commitment_Score
其中声学承诺度：

text
Voice_Commitment = mean(Energy_statement) / mean(Energy_whole_speech) * Pitch_Stability

1. 亲密关系专用声学公式
A. 亲近度
这是比“能量耦合”更细腻的指标，用来区分“激烈对抗”和“亲密互动”，两者能量都可能很高。

text
亲近度(t) = w1 * Pitch_Following(t) + w2 * (1 - |Energy_Asymmetry(t)|) + w3 * Laughter_Synchrony(t)
特征	计算方式	直觉含义
Pitch_Following(t)	就是你已有的音高追随度	模仿对方语调，是下意识的亲近
Energy_Asymmetry(t)	|Energy_A_norm - Energy_B_norm|	亲密对话的能量是平等的。一方嗓门永远压制另一方，是权力不平等
Laughter_Synchrony(t)	A笑声开始后1秒内B也笑的概率	笑点是否在一起，是检测亲密关系的金标准
w1,w2,w3	建议 [0.4, 0.3, 0.3]	—
高亲近度：语调互相追随、能量平等、笑在一起。这是好朋友/亲密伴侣。

低亲近度：各说各话、音量失衡、笑不到一块。这是陌生人或关系疏远。

B. 脆弱性暴露度
真正深度的亲密关系，不在于有多开心，而在于敢于在对方面前展露脆弱。这通常表现为负向情绪的暴露。

text
脆弱性暴露度(t) = (1 - |Valence_A(t) - Valence_B(t)|) * max(-Valence_A(t), -Valence_B(t), 0)
(1 - |Valence_A - Valence_B|)：这部分计算情绪的共时性。你在难过时，对方也同步降低了能量和语调，说明他在承接你的情绪，而不是反驳或无视。

max(-Valence_A, -Valence_B, 0)：确保我们捕捉的是负面情绪的强度。

解读：这个值很高，意味着“一方正在表达强烈的悲伤/恐惧，而另一方完全处在这个情绪里，没有试图逃避或强行拉高情绪”。这是情感连接最深的时刻。

C. 冲突健康度
吵架不一定是坏事。我们要区分“有建设性的冲突”和“破坏性的冲突”。

text
冲突健康度 = TurnSmoothness(t) * (1 - Attack_Duration_Ratio(t))
特征	计算方式	含义
TurnSmoothness(t)	已有的话轮转换平滑度	即便在吵架，依然能听完对方说话，是尊重的底线
Attack_Duration_Ratio(t)	Attack_Time / (Attack_Time + Sustain_Time)	基于你的ADSR包络分析。人在攻击时，声音起音极快。这个比值高，说明句句都在爆发
判定：

高冲突健康度：话轮交替流畅，声音爆发短促但有节制。这是在争论问题。

低冲突健康度：频繁打断，声音持续处于高能量攻击状态。这是在攻击人身。

### 一、通用防御机制评分公式

对任意防御机制 `D`，其得分由三个来源加权合成：

```
Score_D(t) = w1 * Voice_Match_D(t) + w2 * Text_Match_D(t) + w3 * Conflict_Match_D(t)
```

| 子项 | 含义 | 计算公式 |
|------|------|---------|
| `Voice_Match_D` | 声学特征匹配度 | `1 - (欧氏距离(当前声学向量, D的声学模板) / 最大可能距离)` |
| `Text_Match_D` | 语义特征匹配度 | ASR文本中，D对应关键词/句式的密度（归一化后） |
| `Conflict_Match_D` | 声-文矛盾匹配度 | 有些防御靠矛盾检测（否认），有些靠一致性（升华）。这个值取 `Conflict_Score` 或 `(1-Conflict_Score)`，取决于D的模板要求 |
| `w1,w2,w3` | 权重，每种防御不同 | 见下方配置表 |

**声学模板**定义为目标向量 `[Arousal_target, Valence_target, Dominance_target]`，每种防御机制有自己的目标值。

### 三、输出格式

你的系统对每个时间窗口 `t`，输出一个37维的向量：

```
Defense_Vector(t) = [Score_升华, Score_幽默, ..., Score_讽刺]
```

当前激活的防御机制：
```
Active_Defense(t) = argmax(Defense_Vector(t))
if max(Defense_Vector(t)) < θ_active (建议0.5):
    Active_Defense(t) = "无显著防御"
```

**多防御共存**（现实中常见）：
```
Top_Defenses(t) = [d for d in Defense_Vector if Score_d(t) > θ_active]
```

但你提的“王朝更迭”，比序列更高一层。它意味着：

### 一、状态生命周期模型

把一段对话里的任何一个显著状态（比如“愤怒”、“理智化防御”），都看成一个有生有死的“小王朝”。它有四个阶段：

1.  **崛起**：一些微小的、不易察觉的信号开始浮现。
2.  **鼎盛**：完全占据了这个人的声音和语言，是最典型的时刻。
3.  **衰败**：内部矛盾显现，状态开始动摇、不稳定。
4.  **更迭**：旧状态瓦解，新状态诞生，可能是爆发（攻击），可能是投降（退缩），也可能是和解（修复）。

你的系统要做的，不只是在“鼎盛”阶段识别它（这我们之前已经做到了），而是要能判断它**目前处在生命周期的哪个阶段，以及下一个状态可能是什么**。

---

### 二、把“王朝更迭”逻辑翻译成你的声学算法

这需要你在现有基础上，增加三个新的“王朝分析”算子。

#### 1. 状态强度指数

`Power(t)`，代表某个状态当前的“统治力量”。它不是简单的情绪强度。

`Power(t) = Arousal(t) * Purity(t)`

这里的关键是引入 **纯粹度（Purity）** 这个概念。

`Purity(t) = 1 - H_state(t)`

-   `H_state(t)` 是当前状态信号的**熵**。
-   怎么算：比如一个处于“愤怒”鼎盛期的人，他的Arousal高，Valence低，Dominance低。如果这三个值都非常稳定，方差很小，那么 `H_state` 就低，`Purity` 就高，说明这个愤怒非常“纯粹”、稳固。
-   反之，如果愤怒时，Dominance开始剧烈波动（一时想控制，一时又控制不住），`H_state` 就升高，`Purity` 下降。这意味着这个愤怒的统治力在动摇。

**应用**：
`Power` 持续走高 = 状态在崛起/鼎盛。
`Power` 从高点回落 = 状态进入衰败期。

#### 2. 矛盾张力指数

这是预测“更迭”何时发生的核心。王朝的衰败，往往源于内部的矛盾。

`Contradiction(t) = Conflict_Score(t) * (1 - Purity(t)) * (1 + Defensive_Density(t))`

**解读**：
-   **高 `Conflict_Score`**：声-文不对齐，嘴里说的和心里感受不一样。这是内乱的根本。
-   **低 `Purity`**：状态不稳定，统治力下降。
-   **高 `Defensive_Density`**：防御机制被大量调用，说明旧王朝在拼命调兵镇压内部动荡，是崩溃前最后的挣扎。

**预测规则**：
当 `Contradiction(t)` 持续攀升，并突破一个阈值时，就是“王朝更迭”即将发生的强烈信号。旧状态无法再维持。

#### 3. 更迭方向判断

当系统预测“更迭”即将发生时，下一个王朝是什么？这由当前状态的防御机制演化方向决定。我们上一轮做的防御序列分析，在这里就是核心的预测器。

-   **如果旧王朝是“理智化”**：高控制、低唤醒。它衰败时，如果压抑的情感（E）是愤怒，更迭方向大概率是**攻击性**或**被动攻击**。如果压抑的情感是悲伤，更迭方向可能是**退缩**或**压抑**。
-   **如果旧王朝是“愤怒/攻击”**：高唤醒、低效价。它衰败时，如果对方承接了情绪（R重建），更迭方向可能是**升华**或**顺从**。如果对方反击，更迭方向可能是更剧烈的攻击，或转变为**否认/压抑**。
